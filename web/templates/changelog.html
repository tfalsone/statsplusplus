How to update

Stats++ updates by downloading a new release and re-running the launcher. Your league data, settings, and connection are preserved — updating only replaces the app's code.

  1. Stop the app. Close this server (press Ctrl+C in the window running the launcher). This matters on Windows, where running files can't be overwritten.
  2. Download the latest release. Open the Releases page and download the statsplusplus-vX.Y.Z.zip under the newest release.
  3. Extract it over your existing install folder — the same folder that contains start.sh / start.bat — and choose replace / merge when prompted. Keeping the same folder is what preserves your data/ (leagues, settings).
  4. Re-run the launcher (start.bat on Windows, ./start.sh on Mac/Linux). It reinstalls the updated code, cleans up any old files, and relaunches. Your browser reopens to the app.

After relaunching, a “What's New” note confirms the update landed. Tip: if your unzip tool creates a nested statsplusplus-vX.Y.Z/ folder, move the contents up into your install folder so start.sh/start.bat sits at the top level.
